A bit about me

Self-taught developer, problem-solver, and lifelong learner — here's how I got into building for the web.

Available

Hi — I'm Mustapha. I build useful things for the web.

I'm a website and app developer based in Nigeria. I started tinkering with HTML and CSS out of curiosity, and quickly fell in love with how much you can build with just a browser and a text editor.

Today I build responsive websites, small web apps, and lightweight mobile experiences. I care a lot about performance — many of my friends (and I) still use low-end Android phones, so I test everything on modest hardware first.

My approach is simple: understand the real problem, build the smallest version that solves it well, then refine it until it feels effortless.
