A bit about me

Self-taught developer, problem-solver, and lifelong learner — here's how I got into building for the web and what I care about.

Available

Hi — I'm Mustapha. I build useful things for the web.

I'm a website and app developer based in Nigeria. I started tinkering with HTML and CSS out of curiosity, and quickly fell in love with how much you can build with just a browser and a text editor.

Today I build responsive websites, small web apps, and lightweight mobile experiences. I care a lot about performance — many of my friends (and I) still use low-end Android phones, so I test everything on modest hardware first.

My approach is simple: understand the real problem, build the smallest version that solves it well, then refine it until it feels effortless. I write clean, readable code, and I'm always learning something new.

My journey

How I got here

A short look at the key moments that shaped how I build today.

2022 · The spark

First lines of code

Started with a simple HTML page in a mobile code editor — hooked the moment it rendered in a browser. Spent months learning HTML, CSS, and JavaScript fundamentals.

2023 · Building

First real projects

Built my first small websites for friends and local businesses. Learned how to ship, take feedback, and iterate quickly with limited resources.

2024 · Going deeper

Python & apps

Added Python to my toolbox and started building small web apps with a real back end. Began focusing on performance and offline capability for low-end devices.

Now · Open for work

Building for clients

Taking on freelance projects and collaborating with small teams. Currently focused on responsive websites, PWAs, and thoughtful UI design.
